## 🎯 О проекте

**Skill Issue** — это 2D action-platformer, в котором игрок решает задачи по программированию, чтобы продвигаться по уровням. Игра интегрирована с LLM (AI-ассистент), который генерирует уникальные челленджи и адаптирует их сложность под уровень игрока.

### Проблема, которую решает проект
Традиционные методы обучения программированию часто скучны и демотивируют новичков. Skill Issue превращает рутинное написание кода в увлекательный игровой процесс с персонализированным подходом.

**Целевая аудитория:**
- 🎓 Школьники старших классов
- 🎓 Студенты 1-2 курсов IT-направлений
- 💻 Начинающие разработчики

---

## 🛠 Стек технологий

### Frontend (Игра)
- **Godot Engine 4.x** — игровой движок
- **GDScript** — язык скриптинга
- **2D Physics** — физика платформера

### Backend (AI-интеграция)
- **Python 3.8+** — серверная логика
- **FastAPI / Flask** — REST API
- **Hugging Face API** — интеграция с LLM

## ✨ Возможности

- 🤖 **AI-генерация задач** — нейросеть создает уникальные задачи по программированию

- 📊 **Аналитика прогресса** — отслеживание статистики обучения

## 🚀 Установка и запуск

### Быстрый старт (для игроков)
1. Перейдите в папку `Download/`
2. Скачайте билд для вашей ОС
3. Запустите `.exe` (Windows) или бинарный файл (Linux)

### Для разработчиков

#### Требования
- Godot Engine 4.x
- Python 3.8+
- API ключ Hugging Face
